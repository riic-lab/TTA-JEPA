# TTE-JEPA architecture
## Scope
Methods reference for `configs/tte_jepa.yaml` and the baseline configurations. This document contains implementation details only.
## Dimensions and inputs
Let $B$ denote admissions per batch, $A$ anchors per admission, $T$ padded history length, $H=48$ future hours, $C$ dynamic value channels, $M$ indicator channels, $S$ static channels, and $K$ TTE variables. Input dimensions and variable ordering must come from the dataset schema; no channel counts or filesystem locations are embedded in the model.
- History values: `[B,T,C]`; indicators: `[B,T,M]`; static inputs: `[B,S]`.
- History validity: boolean `[B,T]`, right-padded. Anchors: int64 `[B,A]`, zero-based history offsets; anchor validity: boolean `[B,A]`.
- Corrupted future values: `[B,A,48,C]`; indicators: `[B,A,48,M]`; validity: boolean `[B,A,48]`.
- Thresholds: `[B,A,K]`; cumulative TTE labels and validity: `[B,A,K,48]`. Admission lengths: `[B]`. Crossing direction is determined by threshold sign, not sampled independently.
- Floating inputs use a consistent model/device dtype. Indicators are cast to the corresponding values' dtype before concatenation. Loss computations use float32. No records are dropped by the model.
## Student
The history encoder has three Modern Transformer blocks of width 512, eight query heads and eight key/value heads, with head dimension 64. Every block uses pre-RMSNorm ($\epsilon=10^{-6}$), bias-free attention projections, residual connections, and a bias-free SwiGLU feedforward of hidden width 1408. Attention dropout is zero. A final RMSNorm produces query readouts.
Dynamic values and indicators are concatenated and passed through an independent timestep MLP: `Linear(C+M,512) → SiLU → Linear(512,512) → SiLU`. Static covariates pass through `Linear(S,512) → SiLU → Linear(512,512) → SiLU`; the resulting static token precedes hourly history tokens. Static and timestep modules use PyTorch Linear default initialization.
The history stream is causal. Each anchor owns 48 learned 512-dimensional queries, which can attend all queries at that anchor and only the static/history tokens through that anchor. Different anchors never attend each other's queries. History keys and values are shared across anchors within a layer. Queries use identity rotary positions; history uses split-half rotary positions with base 10,000, capacity 8192 including the static token. No learned Fourier position module is added to this student.
After the last block, each query receives the anchor's final history state as a residual before final RMSNorm. Invalid-anchor outputs are zeroed. The student therefore emits $Q\in\mathbb{R}^{B\times A\times48\times512}$.
The shared projection is `RMSNorm(512) → Linear(512,512) → SiLU → Linear(512,512) → Linear(512,256)`. There is no activation between the last two linear layers. Its output is $P\in\mathbb{R}^{B\times A\times48\times256}$.
## Live future teacher
The teacher has its own timestep MLP, independent of the student's: `Linear(C+M,256) → SiLU → Linear(256,256) → SiLU`. It receives no static covariates or history. Its own encoder consists of exactly one Modern Transformer block at width 256 with four query and four key/value heads, head dimension 64, pre-RMSNorm, SwiGLU hidden width 704, and final RMSNorm. Hourly tokens use split-half rotary positions, base 10,000, over offsets 0–47. There are no learned future queries and no cross-attention layer.
At horizon $r$, causal attention accesses only valid future rows up to $r$. Padding keys are excluded explicitly. A completely empty future window produces zero output; partially observed windows retain 48 readouts, including readouts beyond the observed prefix. Thus outputs beyond observation support are not evidence of observed events.
The teacher returns $Z\in\mathbb{R}^{B\times A\times48\times256}$. This encoder is trained by TTE supervision only, not by the student's JEPA loss.
## TTE heads
There are $K$ independent variable-specific heads, with weights shared across horizons. The threshold embedding uses eight learned frequencies initialized as $1.5^j$, $j=0,\ldots,7$, with sine and cosine features. Thresholds are mapped from $[-4,4]$ to $[-1,1]$ without clipping. Conditioning concatenates 16 threshold features and a learned 16-dimensional variable identity; there is no direction embedding.
Each head computes `Linear(288,512) → SiLU → Linear(512,1)`, producing logits `[B,A,K,48]`. The first linear operation is split into equivalent state and conditioning projections. Final biases initialize to -5; other head biases initialize to zero, and head weights and identities use normal initialization with standard deviation 0.02. No EEP supervision is included in pretraining.
## EMA target and objectives
An EMA copy of the complete live future encoder, including its timestep MLP, supplies graph-free targets in evaluation mode. It does not copy the TTE heads. After a successful optimizer step, parameters update as
$$\bar\phi\leftarrow0.996\bar\phi+0.004\phi.$$
Buffers are copied directly. The live teacher and EMA target receive exactly the same supplied corrupted view. The model performs no internal resampling or corruption, and the student receives supplied uncorrupted history.
JEPA uses squared Euclidean distance between L2-normalized 256-dimensional predictions and detached targets, summing feature dimensions, not averaging them:
$$\ell_{a,r}^{\mathrm{JEPA}}=\left\|\frac{p_{a,r}}{\|p_{a,r}\|_2}-\operatorname{sg}\left(\frac{\bar z_{a,r}}{\|\bar z_{a,r}\|_2}\right)\right\|_2^2.$$
Normalization uses PyTorch's epsilon safeguard. All 48 horizons of valid anchors contribute to JEPA, rather than only observed future hours. TTE uses BCE-with-logits against externally supplied cumulative labels and its separate validity mask. Masked label entries must be finite placeholders; masking does not sanitize NaNs.
Within each admission, valid JEPA cells are averaged over anchors and horizons; valid TTE cells are averaged over anchors and horizons separately for each variable. Admission contributions are weighted by $w_i=\sqrt{\min(L_i,c)/L_i}$, where $c$ is the training-split 90th-percentile length supplied by the data pipeline. Additive numerators and denominators are exposed so physical microbatches can be combined before division. The JEPA denominator retains a minimum of one; TTE averages supported variable losses. Total loss is
$$\mathcal L=\mathcal L_{\mathrm{JEPA}}+\frac{1}{|\mathcal K_{\mathrm{valid}}|}\sum_{k\in\mathcal K_{\mathrm{valid}}}\mathcal L_{\mathrm{TTE},k}.$$
## Downstream EEP architecture
The pretrained student path is copied without either teacher. Its complete history encoder is frozen in evaluation mode; the shared adapter and output projection remain trainable. Fresh independent EEP heads receive ordered projected-token prefixes, not token averages. Each head uses `LayerNorm(h·256) → Linear(h·256,256) → SiLU → Linear(256,1)` with zero dropout, producing one cumulative-event logit. Cached raw queries `[N,48,512]` can be passed through `forward_cached`; those inputs are detached while projection and head gradients remain active.

## Initialization and implementation boundaries
Modern attention/feedforward Linear weights use normal initialization with standard deviation 0.02, except attention output and feedforward down projections, which use $0.02/\sqrt{2N}$ for a stack of $N$ blocks. RMSNorm weights start at one. Student query embeddings and projection/head Linear weights use standard deviation 0.02; projection/head biases are zero except the TTE final biases described above.
This document specifies implemented model behavior. Synthetic runtime smokes use reduced dimensions and one student block. The pipeline smoke additionally exercises sampling, corruption, checkpoint selection, and evaluation on synthetic prepared grids. Neither is evidence of full-scale convergence, GPU memory suitability, or mixed-precision parity. The trainer combines loss statistics across physical batches before division, preserves censoring masks, and updates EMA after successful optimizer steps.
## Training and evaluation protocol
Pretraining samples up to sixteen jittered-stratified anchors per admission per epoch, with at least six hours of history and one future hour. Validation uses three deterministic draws per admission with epoch fixed to zero. Thresholds are uniform on $[-4,4]$: positive thresholds query upward crossings and negative thresholds downward crossings. At exactly zero no crossing is positive. Both teachers share the corrupted view: a contiguous span of rounded 25% of valid future hours, independent 15% dropout of non-target continuous channels, and independent 25% dropout of target channels; corresponding indicators are zeroed. Pretraining uses AdamW at $3\times10^{-4}$, weight decay 0.1 excluding one-dimensional parameters, betas $(0.9,0.95)$, effective batch size 512, 5% warmup, and at most 100 epochs. Validation occurs every five epochs; total JEPA plus mean TTE loss selects checkpoints starting at epoch 10. Three stale validation rounds reduce LR by $2/3$; the third reduction stops training.
Downstream training and evaluation use all eligible hourly anchors, with at least four history hours and one future hour. Each non-decompensation task excludes already-positive anchors, accepts an observed incident event as positive, and accepts an event-free negative only with full horizon follow-up and at least one stable observation. Decompensation uses death within 24 hours; all anchors before the discharge/death endpoint remain valid. This endpoint rule is separate from other tasks' censoring.
Downstream AdamW uses LR 0.005 and weight decay 0.1, without warmup. Validation mean EEP AUROC selects the checkpoint every five epochs. Two stale rounds reduce LR by $2/3$; the third reduction stops training. Loss and metrics are admission-balanced within each task; tasks receive equal macro weight. Test AUROC and average precision are computed only after model selection, and per-anchor probabilities, labels, validity, and admission indices are exported for subsequent analysis.
## Baselines
All baseline inputs use the same schema ordering and prepared split identities. Downstream training, validation and test cover every eligible hourly anchor; validity masking does not change cohort membership.

### ICareFM
The static and timestep encoders are two-layer SiLU MLPs. Next-state pretraining applies continuous MSE and categorical cross-entropy to observed logical targets at all adjacent transitions; treatment channels remain inputs but have no reconstruction loss. Missing categorical classes are excluded from the supervised softmax. The next-state decoder is linear, width512 to the dynamic value count. Validation uses one deterministic crop per admission and48 autoregressive predictions with a K/V cache; categorical feedback is one-hot, missing categories and generated observation indicators are zero.
The next-state checkpoint initializes a separate TTE training stage, with the backbone trainable. Each anchor's last observed state is concatenated algebraically with the32-dimensional threshold/identity condition. Each variable has a `544→256→48` SiLU head. The subsequent EEP stage freezes the encoder and fits fresh fixed-endpoint MLPs. Generated hidden-state prefixes are not used for EEP.
### EHRMamba
Static and indicator timestep encoders feed a static token followed by hourly tokens. The scan is causal; padded suffixes do not affect valid preceding states. Each block adds its pre-normalized Mamba-3 output residually; output-projection weights are divided by the square root of depth at initialization. TTE training uses16 jittered anchors and the same compact TTE heads as ICareFM. There is no next-state training stage. Mamba3 kernels are an optional external dependency and require a compatible CUDA environment.
### HEPA
The target uses one learned attention-pooling query over the bidirectional future sequence. History uses its last causal state plus a linear static embedding, followed by LayerNorm. The predictor receives this state and a scalar interval length: `513→512→512→512`, with GELU after the first two linear layers. The event head is `LayerNorm(512)→Linear(512,1)`. Each downstream task copies the predictor and event head independently and supplies its fixed clinical horizon.
Training uses16 stratified jittered cuts per admission (all eligible cuts for shorter stays), with log-uniform integer future intervals up to48 available hours. Validation uses three deterministic interval draws. The loss is $0.95\,\mathrm{L1}+0.05\,\mathrm{SIGReg}$, with gradients through both branches and no EMA. SIGReg uses256 normalized random slices,17 quadrature points on $[0,3]$, Gaussian characteristic-function weighting and a reference batch factor256. It is evaluated over the effective interval batch, with a two-pass gradient cache to preserve gradients across memory-limited encoder microbatches. Projection draws are seeded from the required CLI value and reset for validation. Batches with insufficient samples are rejected, not silently regularized with zero loss.
### XGBoost
MEDS-TAB features concatenate min, max, mean, expanding median and last value for every dynamic coordinate, plus observation counts and rates. Two inclusive prefixes end at $a$ and $\lfloor a/2\rfloor$; the second is the first half of the history, not a trailing-half window. Static covariates are appended. Feature width is $2(5C+2M)+S$ and storage is float32.
Each classifier uses histogram trees with256 bins, depth6, learning rate0.1, row/column subsampling0.8, minimum child weight5 and L2 penalty1. There are at most400 rounds and25 stale validation rounds trigger stopping. Validation AUROC selects the retained tree prefix. Training and validation weights are inverse valid-anchor counts within each admission/task; positives are not upweighted. Feature caches and external-memory quantile matrices avoid loading the entire feature matrix into RAM. Resume skips completed task models and restarts incomplete fits.
